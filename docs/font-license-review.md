# 開発用フォントライセンス確認

比較用の6書体はGoogle Fontsの固定公式配布物から取得し、各ディレクトリのOFL原文、METADATA、SHA-256、バイト数をローカル検証します。通常のProduction buildには採用済みのZen Maru Gothicだけを含めます。

- `lineseedjp`
- `zenkakugothicnew`
- `notosansjp`
- `mplus1p`
- `zenmarugothic`
- `notoserifjp`

各書体の作者・著作権・Reserved Font Nameは同梱するOFLとMETADATAを正とし、削除・改変しません。これらは第三者ライセンス情報で、Demo作者の識別情報ではありません。
