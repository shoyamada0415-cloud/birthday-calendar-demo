# バックアップ互換性

新規書き出しの標準拡張子は `.birthday-backup` です。64バイトの認証済みヘッダー、PBKDF2-SHA-256（600,000回、16バイト乱数salt）、AES-256-GCM（12バイト乱数IV、128-bit tag）を使います。パスワードは保存しません。

復元はファイル名ではなく内容で判定します。現行の暗号化ヘッダーを復号した後は、ZIP構造、容量、entry、SHA-256、画像、参照整合性を検証します。暗号化されていないZIP v0/v1の読込互換も維持します。

匿名化前のヘッダーを使用する暗号化バックアップは、公開Demoでは判定・復号できません。必要なデータは、対応している非公開版で通常ZIPまたは現行 `.birthday-backup` へ移行してください。この変更は識別情報を公開bundleへ残さないためのもので、現行形式の暗号化強度やZIP検証は変更していません。
